# R6.0b + R6.0c Implementation Report

**Date:** 2026-06-01  
**Scope:** DittoBot product catalog (R6.0b), inventory batch + regional assignment (R6.0c), vendor stock panel, minimal tag search.

**Commercial identity (cart, checkout, inventory keys):** see [dittobot-commercial-identity.md](./dittobot-commercial-identity.md) and [ADR-R6E-001](./adr/ADR-R6E-001-commercial-identity-contract.md).

## Routes

| Route | Purpose |
|-------|---------|
| `/admin/dittobots` | Redirect → products |
| `/admin/dittobots/products` | DittoBot product CRUD |
| `/admin/dittobots/inventory` | Physical inventory + batch creation |
| `/admin/dittobots/assignment` | Assign `available` units to regional vendors |
| `/admin/dittobots/audit` | Placeholder audit summary |
| `/dashboard-vendor/dittobots` | Vendor stock panel (tabs) |
| `/profile/dittobots` | User activation (unchanged) |
| `/vendor/dittobots` | Public storefront CTA for purchase |

## Validation Checklist

- [ ] Super Admin can create DittoBot product with subcategory + min 1 tag
- [ ] Product uses official vendor store, `is_ditto_bot=true`, `price_mode=centralized`
- [ ] Batch creates units with `DTB-000001` serials and random activation codes
- [ ] Assignment only works for `available` units → `assigned` + `assigned_at`
- [ ] Official vendor cannot be assignment target
- [ ] Vendor panel shows stock aggregates and serial drilldown
- [ ] Mis DittoBots CTA links to `/vendor/dittobots`
- [ ] Marketplace client search matches tags when present in listing payload
- [ ] `npm run lint && npm run test && npm run build` pass
